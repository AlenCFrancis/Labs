# Machine Learning Regression Models

This repository contains machine learning projects focused on various regression algorithms (e.g., Linear Regression, Decision Trees, Random Forest) implemented in Jupyter Notebooks.

---

##  Important: Dataset Setup & File Paths

The notebooks in this repository were developed and executed using **Google Colab** / **Jupyter Notebooks (Anaconda)**. Because datasets were loaded from local environment paths during execution, you will need to update the file paths or download the datasets locally before running the code.
